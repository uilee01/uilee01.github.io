Overview

Two branded websites, one for a Hong Kong cross-border SMS provider and one for an accessibility technology company. Both had to explain their value in the first screen, hold their own rhythm across long pages, and stay readable on the small screens most overseas visitors use.

Balancing content against restraint

Corporate sites and portfolio sites fail in opposite ways. A corporate site carries the brand and wins leads; a portfolio site is read by other designers. Both need business points, work, team and contact details on one page, yet a first screen stuffed with everything convinces nobody. And because most overseas visitors arrive on a phone, a long page that collapses on narrow screens loses half its readers.

Value first, everything else layered down

Keep the first screen to one value proposition and one clear action, and push everything else into layers: long pages get explicit section headings and generous spacing, with paragraphs capped at three lines. One palette and one type scale run through every page, and icons are redrawn on a shared grid so listing pages, detail pages and mobile views feel like one product. Responsive is a re-order of priorities rather than a proportional shrink: dense tables and multi-column blocks collapse into swipeable modules on narrow screens.

Scope

  1. First-screen value proposition and primary action
  2. Capability modules and icon grid
  3. Company timeline and milestones
  4. Data visualisation and information density
  5. Responsive re-order and mobile adaptation

One website design language

Both sites shipped on one shared design language: a single palette, type scale, corner radius and icon grid carried across every page, with desktop and mobile following the same grid logic so new content never needs a new rule. Handover included high-fidelity screens, icon sources and a component specification for the front-end team.

What comes next

Next is aligning the site specification with the content-management back end so marketing can publish without breaking the rhythm, and adding a light and dark theme pair for clients with different brand habits.

My Role

Owned the brand direction and interface design for both sites independently, covering the first screen, information architecture, icon system and responsive adaptation, and delivered high-fidelity screens plus a component specification for engineering.
